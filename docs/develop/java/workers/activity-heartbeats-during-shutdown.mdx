## Enable heartbeats during graceful shutdown

In Temporal Java SDK v1.36.0, `WorkerOptions.Builder.setAllowActivityHeartbeatDuringShutdown(boolean)` is experimental and defaults to `false`.

Set `setAllowActivityHeartbeatDuringShutdown(true)` to let Activities keep heartbeating during a graceful Worker shutdown.

By default, after a graceful Worker shutdown is requested, `ActivityExecutionContext.heartbeat()` sends no heartbeat and throws `ActivityWorkerShutdownException`.
Without the option enabled, an Activity still running during the shutdown grace period cannot refresh its heartbeat deadline, so the Temporal Service may time it out and retry it while it is still running.

## Finish Activities within the termination grace period

With `setAllowActivityHeartbeatDuringShutdown` enabled, Activities are no longer notified of Worker shutdown through `ActivityWorkerShutdownException`; they must finish within the termination grace period on their own.

`WorkerFactory.shutdownNow()` ignores this option: after a non-graceful shutdown, `heartbeat()` still throws `ActivityWorkerShutdownException`.

## Tune shutdown checks for tests

`WorkerFactoryOptions.Builder.setShutdownCheckInterval` can speed up Worker shutdown in some testing scenarios; changing it in production is discouraged.
